This document separates the Apache-2.0 license for original MSK-Bench source contributions from the terms that govern third-party code, datasets, simulation assets, and pretrained weights. It records provenance and release boundaries; it is not legal advice or a substitute for the providers' terms.

## Pretrained weights

The MuscleMimic integration obtains the official [amathislab/mm-fullbody-base](https://huggingface.co/amathislab/mm-fullbody-base) weights from the network for real pretrained inference. No checkpoint is stored in this repository. MuscleMimic's Apache-2.0 source-code license is not a blanket license for weights or their training data; consult the checkpoint provider's current terms.

A zero-base or offline dynamics check is not pretrained-policy validation. Commands and reports must state whether a non-null pretrained base policy was actually loaded.
