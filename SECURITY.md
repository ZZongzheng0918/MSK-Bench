# Security policy

## Supported versions

Security fixes are applied to the latest source release on the `code` branch. The `main` branch hosts the project website.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability, leaked credential, or unsafe artifact. Use GitHub's private vulnerability reporting feature for this repository. Include the affected version or commit, reproduction steps, impact, and any suggested mitigation.

For ordinary bugs, use the public issue tracker.

## Sensitive research artifacts

Never attach Hugging Face tokens, private dataset files, unpublished checkpoints, personally identifying participant data, or machine-specific credential files to an issue or pull request. If a report depends on restricted data, describe the minimum reproducible structure without redistributing the data.
